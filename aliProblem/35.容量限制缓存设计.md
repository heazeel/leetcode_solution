我们经常需要将一些数据储存到浏览器的 storage 里，但 storage 容量有严格限制，请设计一个读写 storage 的类，在写入新内容时如果容量已达上限，先删除之前的内容，从而为新的数据留出空间。

数据删除优先级：

1）读取次数最多的内容优先保留

2）读取次数相同的内容最近读取或保存的优先保留

> 我们忽略保存内容的长度，只限制保存内容的个数

示例：

```
const storage = new Storage(2);  // 限制最多存 2 个 cookie 内容
storage.setItem('a', 1);
storage.setItem('b', 2);
storage.getItem('a'); // 返回 1
storage.setItem('c', 3); // 删除 b
storage.getItem('b'); // 返回 undefined
```

#### js 代码如下

```js
class Storage {
  // your code here
  constructor(capacity) {
    this.capacity = capacity;
    this.map = new Map();
  }

  setItem(key, value) {
    if (this.map.size === this.capacity) {
      const firstKey = this.map.keys().next();
      this.map.delete(firstKey);
    }

    this.map.set(key, value);
  }

  getItem(key) {
    const res = this.map.get(key);
    this.map.delete(key);
    this.map.set(key, res);

    return res;
  }
}

const storage = new Storage(2);
storage.setItem("a", 1);
storage.setItem("b", 2);
storage.getItem("a");
storage.setItem("c", 3);
storage.getItem("b");
```
