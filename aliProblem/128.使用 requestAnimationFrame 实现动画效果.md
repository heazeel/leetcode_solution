题目：使用 requestAnimationFrame 实现一个 Ticker 类
* 包含 addAnimation、start、cancel 三个对外方法
* addAnimation 可以处理 位移、缩放、旋转 三种类型的动画
* 调用 start 从头开始播放
* 调用 cancel 取消播放。


#### js代码如下
```js
class Ticker{
  constructor(element,duration) {}
  addAnimation(options) {}
  start() {}
  cancel() {}
}
```
