Interaction description:
1. There are 100 small squares in the div as shown in the above picture
2. Implement a React or Vue component
	<Range min={10} max={20} onChange={(minValue, maxValue)=>{}</Range>
	1. The attribute min is passed in as 10 and max is passed in as 20, so when initializing the rendering component, the 10-20 cells from top to bottom and left to right are selected
	2. When onChange, return the maximum and minimum values
3. After initializing rendering, how do I select a grid? The interaction description is as follows:
	1. After mouse down in the div container, start selecting. When mouse move, select small squares based on the coordinates of the mouse down and the current position formed by the rectangle. When mouse up, end the selection, and the selected small squares turn blue
	2. It can only be selected consecutively from left to right and from top to bottom, and cannot be clicked to skip selection
	3. Every time the mouse down is restarted, the selection will start again and the previously selected results will be cleared
	4. Mouse up outside the scope is considered as canceling this operation
