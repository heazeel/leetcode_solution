> 场景：前端通过 GET 请求发送监控日志，但最大字符数不能超过 100 个字符（含协议类型、域名、路径、参数）

要求：写一个 send() 函数生成上报链接，以 <span style="color:red;">**“尽可能上报更多的字段”**</span> 的原则进行拼接，即按照字段总字符数数从小到大排列进行拼接，超过总长度后截断即可

例如上报数据为：
```
const data = {
  api: 'mtop.trip.train.fetch',
  v: '1.0',
  data: {type: "local"},
  code: 500,
  delay: 2000,
  message: "请求失败"
}

send(data);

结果应为（100个字符）：
https://log.fliggy.com/c.gif?v=1.0&code=500&delay=2000&api=mtop.trip.train.fetch&data=%7B%22type%22%
```
