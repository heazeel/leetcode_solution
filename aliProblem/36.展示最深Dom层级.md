找出 html 中最深 Dom 层级，并console展示出来。

console展示时只保留元素的tag名称，每层加换行，子元素加两个空格做缩进

例如：
```html
<div id="root">
	<p>本节点不是最深层级不会输出</p>
	<div>
		<span>本节点不是最深层级不会输出</span>
		<div>
			<h3>最深层级并列多个时，输出第一个</h3>
			<h4>本节点是并列最深但不是第一个，所以不输出</h4>
		</div>
	</div>
</div>
```

console.log(showMaxDeepth(document.getElementById('root'))) 输出结果为：
```
<div>
	<div>
		<div>
			<h3>
			</h3>
		</div>
	</div>
</div>
```
