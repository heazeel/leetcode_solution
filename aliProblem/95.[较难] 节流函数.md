实现一个节流函数 function debounce(function, duration){}

例如：

```
const fetchData = function(){console.log('fetch!')}
const newFetchData = debounce(fetchData, 1000);

newFetchData();
newFetchData();
newFetchData();
setTimeout(() => {
  newFetchData();
}, 1100)
```

结果：
```
fetch!
fetch!
```
