> parseBytes 的实现，将一个表示文件大小的字符串转换成最终的数字，这个数字表示文件的 byte 数大小。

举例：

```js
parseBytes('123'); 				// 123
parseBytes('1.2 Kb'); 		// 1228.8 = 1.2 * 1024
parseBytes('1.2 Mb'); 		// 12886411837.44 = 1.2 * 1024 * 1024
```

使用场景：在一些配置文件中，可能会设置一些文件的最大最小限制，为了便于用户配置，会使用语义化的字符串作为输入，而实际使用的时候，一定是都转化为 byte 单位的数据进行比较大小。
