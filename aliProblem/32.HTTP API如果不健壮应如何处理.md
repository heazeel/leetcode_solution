#### 模拟场景：
有一个天气预报的页面可以展示天气信息。
天气信息，是由服务商A提供的http形式的api，不过由于A提供的服务不太稳定，所以页面也会同时访问服务商B提供的一个api。

#### 要求：
1. 主要设计一个JavaScript函数，此函数会返回天气信息，并配上React UI来做调用来展示天气信息。
2. 这个函数中，会访问2个天气API，这2个API的权重是相同的。
3. 这2个API都不太稳定，可能会很快返回，也可能会直接报错，也可能会超过5分钟pending无反应。
4. 将这个JavaScript函数，放在一个页面调用。
5. 示例代码用fetch()去请求API，不要借用其他三方库。

#### 以下是加分要求
1. 请用TypeScript来书写上述代码。
2. 如果各个环节发生异常，程序要易于调试、跟踪异常。
3. 代码要易读、易维护。
4. 参考岗位要求，可以自己在题目中加戏（超过题目要求），将知识点放到这个题目中，以便于展示自己擅长的知识点。

#### 以下内容不做要求：
1. API的地址随意编写一个就好，无需考虑鉴权的问题。
2. React UI组件仅仅用来示意工具函数的调用，所以简单实现做就好。	
3. 代码可以在VSCode等IDE里写好，贴进来即可。
