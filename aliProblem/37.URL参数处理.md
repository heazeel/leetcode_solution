#### 实现一个 UrlTools 类，包含两个功能：

##### 1. 把一个URL查询字符串解析成一个键值对的集合。

示例：
```
// 输入：查询字符串
UrlTools.parse('?foo=bar&abc=xyz&abc=123')

// 输出：一个键值对的对象
{
  foo: 'bar',
  abc: ['xyz', '123'],
}
```

##### 2. 把键值对的集合转换为URL查询参数

示例：
```
// 输入：键值对集合
UrlTools.stringify({
  foo: 'bar',
  abc: ['xyz', '123'],
});

// 输出：URL查询字符串
'?foo=bar&abc=xyz&abc=123'
```

```js

  // your code here
};

console.log('UrlTools.parse', UrlTools.parse('?foo=bar&abc=xyz&abc=123'))；

  foo: 'bar',
  abc: ['xyz', '123'],
}));
```
