## 描述
实现 `whitelistToArray` 函数，支持中英文逗号分隔。

## 测试用例

```js
stringToArray('1') // => ['1']
stringToArray('1,2,3,4') // => ['1', '2', '3', '4'] // 英文逗号

stringToArray('1，2,3,4') // => ['1', '2', '3', '4'] // 中文逗号
stringToArray('1,,2,3,,,4') // => ['1', '2', '3', '4'] // 多个逗号
stringToArray(' 1,  2,3,, ,4\t ') // => ['1', '2', '3', '4'] // 空格
stringToArray('') // => []
stringToArray() // => []
stringToArray(true) // => []
```
