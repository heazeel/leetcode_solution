> 题目：请用 HTML、CSS 和 JavaScript 实现一个简单的登录页面。

页面包括一个输入框用于输入用户名，一个输入框用于输入密码，以及一个登录按钮。
用户名和密码的输入框需要有基本的样式，如边框、背景色等。
登录按钮需要有基本的样式，如背景色、字体颜色等。
当点击登录按钮时，需要验证用户名和密码是否符合指定要求（例如，用户名不能为空且密码必须大于6个字符），如果不符合要求，则显示错误信息；如果符合要求，则弹出提示框显示登录成功。
页面需要具备一定的响应性，即在不同设备上能够适应不同的屏幕尺寸和方向。

要求：
使用 HTML5 标签和语义化布局。
使用 CSS3 实现样式效果，可以使用 CSS 预处理器（如 Sass、Less）加分。
使用 JavaScript 实现表单验证和交互效果，可以使用 ES6 或以上版本的语法。
可以使用任意开发工具和框架，但需要注明使用的技术栈。推荐使用 React.js
