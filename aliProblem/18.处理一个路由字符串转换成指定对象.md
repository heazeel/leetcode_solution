> 给定以下路由字符串

路由字符串的结构如下：

```
let routes = '/users/{userId}/posts/{postId}/comments/{commentId}/{hashId}'
```

返回结果应该如下：

```
{
  staticParts: ['users', 'posts', 'comments'],
  dynamicParts: {
    userId: 1,
    postId: 2,
    commentId: 3,
    hashId: 4
  }
}
```
