目标：

你的任务是实现一个 Logger 类，该类支持链式调用，并具有基本的日志记录和防抖日志记录功能。

基本要求：

1. Logger 类应该有一个 log 方法，用于立即输出日志信息到控制台。
2. Logger 类还应该有一个 debounceLog 方法，该方法接受两个参数：日志信息和防抖时间（毫秒）。该方法应实现防抖功能，即在指定的防抖时间内，如果连续调用，则只有最后一次调用会被执行。

示例用法：

const logger = new Logger();

logger.log('Hello').debounceLog('This should not show', 100).log('World');

// 假设在 100 毫秒内没有再次调用 debounceLog
// 预期输出：
// Hello
// World
