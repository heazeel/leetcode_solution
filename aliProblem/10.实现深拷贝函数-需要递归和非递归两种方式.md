题目：实现深拷贝函数-需要递归和非递归两种方式

目标：

你的任务是实现一个名为 deepCopy 的函数，该函数能够执行一个对象的深拷贝操作。深拷贝意味着复制对象及其所有嵌套对象的属性，确保原始对象和复制对象之间不共享任何引用。

基本要求：

1. deepCopy 函数应该能够深拷贝以下类型的值：Object、Array、Date、Map、Set、基本数据类型（如 Number、String、Boolean 等）。
2. 实现两个版本的 deepCopy 函数：
   ○ 一个使用递归方式实现。
   ○ 另一个使用非递归方式实现（提示：可以使用栈或队列）。
3. 确保你的实现能够处理循环引用的情况。

示例用法：

const obj = {
num: 0,
str: 'string',
bool: true,
arr: [1, 2, 3],
obj: { key: 'value' },
date: new Date(),
map: new Map([['key1', 'value1']]),
set: new Set([1, 2, 3])
};

const copiedObjRecursive = deepCopyRecursive(obj);
const copiedObjNonRecursive = deepCopyNonRecursive(obj);

console.log(copiedObjRecursive, copiedObjNonRecursive);

#### js 代码如下

```js
const deepCopy = (obj) => {
  if (obj === null || typeof obj !== "object") {
    return obj;
  }

  if (Array.isArray(obj)) {
    return obj.map((item) => deepCopy(item));
  }

  if (obj instanceof Date) {
    return new Date(obj);
  }

  if (obj instanceof Map) {
    let map = new Map();
    obj.forEach((value, key) => {
      map.set(key, deepCopy(value));
    });

    return map;
  }

  if (obj instanceof Set) {
    let set = new Set();
    obj.forEach((value) => {
      set.add(deepCopy(value));
    });

    return set;
  }

  if (obj instanceof Object) {
    let _obj = {};
    Object.entries(obj).forEach(([key, value]) => {
      _obj[key] = deepCopy(value);
    });

    return _obj;
  }
};

const obj = {
  num: 0,
  str: "string",
  bool: true,
  arr: [1, 2, 3],
  obj: { key: "value" },
  date: new Date(),
  map: new Map([["key1", "value1"]]),
  set: new Set([1, 2, 3]),
};

const _obj = deepCopy(obj);
console.log(_obj);
```
