### 大模型开发范式

**RAG：** 语义理解
**Agents：** 逻辑推理，规划逻辑链、行动链，每一步调用什么 API 去解决问题，模拟像人类的思考方式去解决问题

那为什么是 AI 呢，除了响应公司 **all in ai** 的口号外，大模型其实是前端程序员的巨大机遇，为什么这么说，因为 python 和 js 是大模型时代最火的两个语言，我们打开 OpenAI API 的官方网站，其官方支持的 API 只有 Python 和 JavaScript，包括像大模型流行的应用框架 LangChain、dify 等等，都是只提供了 Python 和 JavaScript 版本。python 自然不用多说，而 js 是唯一的全栈语言，再加上很多能力都已经云服务化了，开发者不需要关心很多技术细节，那什么变的更重要了，就是对用户的理解会变得更重要，这些恰好是前端程序员所擅长的。

**fine-turning：** Fine-tuning 技术可以用于优化预训练模型，以提高其在特定任务中的性能，例如问答、文本摘要、语言理解等
**Prompt 和 Embedding** 是 AIGC 模型的核心功能，语言处理应用。例如，它们可以用于聊天机器人、语言翻译、摘要生成、文本分类等
